GitHub Pages 部署指南

若要將此網頁部署至 GitHub Pages 並且讓 ./VRM/01.vrm 順利讀取，請遵照以下步驟：

1. 資料夾結構要求
my-vrm-repo/
├── index.html  (本網頁)
└── VRM/
    ├── 01.vrm  (預設模型)
    └── 02.vrm  (其他模型)
2. 上傳至 GitHub

將專案推送至您的 GitHub 儲存庫（Repository）的 main 或 master 分支。

3. 啟用 GitHub Pages
  1. 進入您的 GitHub Repository 頁面。
  2. 點選上方分頁的 Settings。
  3. 在左側欄點選 Pages。
  4. 在 Build and deployment 的 Source 選擇 Deploy from a branch。
  5. Branch 選擇 main (或 root) 並按下 Save。
  6. 稍等 1-2 分鐘即可透過 GitHub 產生的網址在瀏覽器（支援 WebCam 攝影機）中開啟！
